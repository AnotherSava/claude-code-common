When something concrete turns up that I can settle in this session — a discrepancy, a misfiled
section, a count that disagrees — do it and report it; don't close with "Memo it?". Memos are for
ideas the user drops and for work that genuinely cannot happen now (another box with no live
session, a decision that is theirs to make).

**Why:** twice on 2026-09-26 an offered memo came back as "do it right away" and "why memo? if you
want to do something with it, do it now".

**How to apply:** before writing a park-it line, ask whether the fix is reachable now; if it is,
the line becomes the fix. See [[feedback_gap_in_a_gate_is_a_fix]].
