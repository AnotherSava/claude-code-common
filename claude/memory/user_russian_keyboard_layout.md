The user switches between English and Russian keyboard layouts, and a short reply sometimes arrives typed in the
wrong one. Read a lone Cyrillic letter by the key it sits on in the standard ЙЦУКЕН layout: "н" is the Y key, so
"н" answering a yes/no question is "y", a yes. Seen 2026-11-05, as the answer to a "Continue?".

**How to apply:** treat it as the Latin letter on the same key when the reply is a single letter or an obvious
one-word answer to the question just asked. When the mapped letter does not fit the question, ask instead of
guessing.
