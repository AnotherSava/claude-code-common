When consolidating rule documents (skills, feedback memories), state each rule with a one-clause
reason and drop the dated "real case" narratives.

**Why:** asked 2026-09-29 while consolidating agent messaging into the `peer` skill: "consolidate and
remove dated". The dated stories made `peer_messaging.md` 29k characters; rule plus reason came to 6k.

**How to apply:** new rule text gets no incident story. Existing files lose theirs when they are next
consolidated, not in a sweep — the remaining peer-related ones are parked as a memo in the dotfiles
repo.
