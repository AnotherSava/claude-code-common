  type: feedback

A field that edits a value in place on a page people read looks like the value at rest: its border and padding are pulled back so the text starts in the value column, the box appears only on hover and focus, and its save button appears only once something changed.

**Why:** on 2026-11-01 a full-box name field on the trips booking page's From/To rows was called "quite messy" beside the three bordered buttons of the merge question under it; the borderless-at-rest version was approved.

**How to apply:** one-line value fields on read pages. Multi-line editors (the extras text areas) keep their boxes. Related: [[feedback_minimal_ui_chrome]].
