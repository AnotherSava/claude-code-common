Files in `claude/` are symlinked to `~/.claude/` and files in `git/hooks/` are symlinked to `~/.git-hooks/`. When adding a new file that needs global installation, add the symlink command to **both** install blocks in `README.md` and a matching entry to `LINKS` in `claude/hooks/check-install.py` — `claude/tests/install-links.py` fails the commit gate when those disagree, since a link documented in one place and checked in neither is how `~/.claude/conventions` came to be missing on both machines with nothing reporting it.
